📚Library Management System

A simple and interactive Library Management System built using Python and Streamlit.

The application allows users to manage books and library users through an easy-to-use web interface.

✨ Features

- 📕 Add new books
- 📚 View all available books
- 🔍 Search books by Book ID or Book Name
- 👩‍🎓 Register library users
- 📤 Issue books to registered users
- 🔢 Automatic Book ID generation
- 🆔 Automatic User ID generation
- 📱 Mobile number validation
- 🚫 Duplicate book name checking
- 🎨 Animated and interactive Streamlit UI
- 📊 Library statistics on the Home page

🛠️ Technologies Used

- Python
- Streamlit
- HTML/CSS for UI animations and styling
- Text files for storing book and user data

▶️ How to Run

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder

cd library-management-system

3. Install the required library

pip install -r requirements.txt

4. Run the Streamlit application

streamlit run main.py

The application will open in your browser.

💾 Data Storage

The application stores:

- Book information in "books_data.txt"
- User information in "users_data.txt"

For demonstration purposes, the repository should contain only sample/dummy user data, not real personal information.

🎯 Purpose

This project was created to practice Python programming, file handling, validation, and Streamlit application development while building a simple real-world application.
